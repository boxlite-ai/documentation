BoxLite CI runs jobs from your existing GitHub Actions workflows in temporary Linux boxes. Keep your workflow triggers, Actions, logs, and results in GitHub. BoxLite prepares the execution environment and reclaims it after the runner exits.

Move one job or an entire workflow to BoxLite by changing its `runs-on` label. Choose a separate machine size for each job.

```diff .github/workflows/ci.yml
 jobs:
   build:
-    runs-on: ubuntu-latest
+    runs-on: boxlite
```

## How jobs run

A **workflow** is a YAML file in `.github/workflows/`. Each **job** runs its steps on a **runner**, the program that executes GitHub Actions. A **box** is the temporary virtual machine that hosts that runner.

```text
GitHub workflow
├── build job → runner in box A → build steps → cleanup
└── test job  → runner in box B → test steps  → cleanup
```

Steps in one job share a workspace and local Docker environment. Different jobs use separate boxes. Use artifacts to transfer files between jobs; `needs` controls execution order, not filesystem sharing.
