Your agent runs inside a Cloud box, with its own filesystem, shell, and network access. Install it, configure its model connection, and give it a task.

Each guide creates a box with the native SDK, then uses the CLI and the agent's own configuration. Real model-provider keys stay outside the box. **An HTTP service and automatic stop/wake are optional additions.**

## Before you start

Install the [Cloud CLI and Python SDK](/cloud/quickstart), and configure the native Cloud variables `BOXLITE_REST_URL` and `BOXLITE_API_KEY` on your workstation. Both SDK and CLI use that connection. Keep the Cloud API key outside the box.

Each `create.py` asks for your SiliconFlow key without echoing it. The SDK sends that value only as a host-scoped `Secret`; files copied into the box contain `<BOXLITE_SECRET:siliconflow>` instead.

```text
Agent or model bridge in the box     BoxLite egress proxy       SiliconFlow
Authorization: Bearer <placeholder> → inject for allowed host → real credential
```

The agent can call the model, but its configuration does not contain the real provider key. `hosts=["api.siliconflow.com"]` limits where substitution occurs; it does not replace an [egress allowlist](/cloud/network-policy).

Python and Node clients use the system CA bundle specified in each create script, so TLS verification includes BoxLite's proxy certificate. Do not disable certificate verification. See [Secret behavior and parameters](/manage-sandbox/secrets-and-security).

The examples use SiliconFlow and `Qwen/Qwen3.5-9B`. Claude Code and Codex need the [protocol bridge](/cloud/agent-in-box/model-bridge) for this provider. With a native protocol endpoint, configure its own host-scoped secret instead.

`auto_stop=0` keeps the box running, and `auto_delete=0` retains its disk after stopping. Stop it when finished, or choose another [lifecycle policy](/cloud/box-lifecycle). HTTP serving and automatic stop/wake remain optional.

<Note>
  These examples were verified with real model calls and file tools. Acceptance also checked host-scoped injection, relevant guest files and process environments, and Secret substitution after the optional Hermes restart.
</Note>
