# Fractional CPU and independent memory sizing acceptance

Target: app production via https://api.boxlite.ai. Date: 2026-11-13.

## Runtime evidence

Created, started, inspected, and executed Python in boxes with 0.125, 0.25, 0.5, and 1 CPU, each with 256 MiB RAM. A five-second busy loop consumed approximately 0.624, 1.244, 2.492, and 4.996 seconds of process CPU time respectively. Guest-visible CPU count was 1 in every case. The first 0.125 execution returned an abnormal exit with no output; the retry passed. No sustained-load performance or billing claim is derived from this short probe.

REST rejected 0.124 CPU (below the minimum) and 0.1255 CPU (not a 0.001-core multiple). CLI created and ran a 0.5 CPU box, stopped and started it, then reported Cpus=0.5 and Memory=268435456. The box was removed.

All seven independent CPU/memory combinations passed creation, start, returned-config checks, and guest /proc/meminfo inspection:

| CPU | Memory MiB |
|---|---|
| 0.125 | 128 |
| 0.125 | 1024 |
| 0.125 | 4096 |
| 0.5 | 128 |
| 0.5 | 4096 |
| 1 | 128 |
| 2 | 256 |

The first 0.125/128 request hit a network error; the first 0.125/1024 run hit command-output errors. Both passed on repeat and were not initially counted as passes. All created test resources were removed.

## OSS boundary and source verification

A real local macOS runtime rejected BoxOptions(cpus=0.5, memory_mib=256) with UnsupportedError: fractional cpus requires a Linux host. No box was created. Fractional CPU on standalone OSS Linux was not independently executed in this session; its Linux/jailer/cgroup requirements, best-effort quota behavior, 16-CPU bundled-kernel ceiling, and updated Python/Node/Rust/C API types were verified against boxlite origin/main. Cloud Linux quota enforcement was observed in the runtime evidence above.

Updated stale integer-only API references, nproc guidance, and 255-CPU descriptions alongside the Cloud/OSS sizing pages. Removed account-specific ceilings presented as universal limits. Organization resource limits are checked independently in apps/api/src/box/services/per-box-limits.ts.

Validation: documentation lint, navigation/MDX structure checks, generated llms index, Mintlify build, and broken-link checks passed. Browser review confirmed Cloud language tabs and the OSS fractional-CPU section.
